# Maya CLI (headless assistant) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `maya` binary for macOS and Linux that runs Maya's assistant role with no window, so sessions on an SSH box or container appear on the main Maya's board and can be started, resumed and driven from there through tmux.

**Architecture:** The Rust crate is split into a workspace: `core/` (everything without Tauri or AppKit, including the network layer and the local session actions), `src-tauri/` (the app, depending on core) and `cli/` (the new binary, depending on core). One trait, `core::terminal::Terminal`, is the only platform seam: the app implements it with Terminal.app and AppleScript, the CLI with tmux. The CLI reuses `core::net::client` unchanged through its `Executor` and `ClientNotify` traits.

**Tech Stack:** Rust 2021 (std threads, no async), serde/serde_json, tungstenite 0.30, tmux, GitHub Actions (`cross` for musl targets), vitest for the one TypeScript change.

**Spec:** `docs/superpowers/specs/2026-09-30-maya-cli-design.md`

## Global Constraints

- `core/` never depends on `tauri`, `tauri-build`, `objc2*`; CI compiles it on Linux.
- The CLI binary is named `maya` (crate `maya-cli`), assistant-only; it never runs the main and never notifies, speaks or listens.
- Config file: `~/.claude/maya/config.json`, the same `config::Config` the app writes. No environment variables.
- Exit codes: 0 success; 1 failure; 2 usage or configuration error.
- Messages reused verbatim from the app's client: `Removed by the main Maya; pair again.`, `Not paired with a main Maya yet; pair in Settings.`, `The main Maya failed to prove it knows the pairing code.`, `Wrong or expired pairing code.`; new: `run \`maya pair\` first`, `the CLI is assistant-only`, `tmux is not installed on <machine>`, `This session is not in tmux; only replies reach it.`, `Attach with: tmux attach -t <name>`.
- tmux session names: `maya-` + the first 8 hex characters of `protocol::new_id()`.
- Card field `terminal: Option<String>` serialises as `terminal`, `#[serde(default, skip_serializing_if = "Option::is_none")]`.
- Release assets: `maya-macos-arm64`, `maya-macos-x86_64`, `maya-linux-x86_64`, `maya-linux-aarch64` on the same `v<version>` release; `maya --version` prints the workspace version.
- Conventional commits, one concern per commit, each ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Never commit to main, never push.
- Commands: `cargo` needs `PATH="$HOME/.cargo/bin:$PATH"`; run cargo from the repo root (workspace) after Task 1; frontend `pnpm exec vitest run` and `pnpm exec tsc --noEmit` from the root; `sh scripts/test-ear.sh`.
- The app's existing suites (cargo, vitest, tsc, ear) stay green after every task.

## Review Focus

1. A `claude` running headless outside tmux: replies still reach it through its inbox, and answers/slash commands fail with `This session is not in tmux; only replies reach it.` (Task 5 tests `name_for_tty` → None and Task 3 tests the message through `FakeTerminal`).
2. `maya run` started while the config's role is `main` or has no token exits 2 with the message and starts nothing (Task 7 test).
3. A tmux binary missing on the machine: `open` fails with `tmux is not installed on <hostname>`, which reaches the main's dialog as the command's error (Task 5 test with a bogus tmux path).
4. Prompt text containing quotes, `$` and newlines survives the tmux command line (the prompt goes through the prompt file, so only the file path is quoted; Task 5 tests `open` quoting with a path containing a space and a quote).
5. Two `maya run` processes on one machine would both connect with the same token; the second replaces the first on the main. Task 7 refuses to start when the status file says another `run` is alive (pid check) with `maya run is already running (pid N)`, exit 2.

```rust
//! The platform seam: where a session's terminal lives and how keys reach it.
use std::path::{Path, PathBuf};

pub trait Terminal: Send + Sync {
    /// Runs `command` (a shell line) in a visible terminal in `cwd`, under
    /// `label` where the terminal has names (tmux); returns that name.
    fn open(&self, command: &str, cwd: &Path, label: &str) -> Result<Option<String>, String>;
    /// Types `text` then Enter into the terminal hosting `tty`.
    fn type_line(&self, tty: &str, text: &str) -> Result<(), String>;
    /// Brings the terminal hosting `tty` forward; Err says what to do instead.
    fn focus(&self, tty: &str) -> Result<(), String>;
    /// The terminal's own name for the pane hosting `tty`, if it has one.
    fn name_for_tty(&self, tty: &str) -> Option<String>;
}

#[cfg(any(test, feature = "test-support"))]
pub use test_support::{Call, FakeTerminal};

#[cfg(any(test, feature = "test-support"))]
pub mod test_support {
    use super::*;
    use std::collections::HashMap;
    use std::sync::Mutex;

    #[derive(Debug, Clone, PartialEq)]
    pub enum Call {
        Open { command: String, cwd: PathBuf, label: String },
        Type { tty: String, text: String },
        Focus { tty: String },
    }

    #[derive(Default)]
    pub struct FakeTerminal {
        pub calls: Mutex<Vec<Call>>,
        pub names: Mutex<HashMap<String, String>>,
        pub fail_type: Option<String>,
    }

    impl Terminal for FakeTerminal {
        fn open(&self, command: &str, cwd: &Path, label: &str) -> Result<Option<String>, String> {
            self.calls.lock().unwrap().push(Call::Open { command: command.into(), cwd: cwd.into(), label: label.into() });
            Ok(Some(label.into()))
        }
        fn type_line(&self, tty: &str, text: &str) -> Result<(), String> {
            if let Some(e) = &self.fail_type {
                return Err(e.clone());
            }
            self.calls.lock().unwrap().push(Call::Type { tty: tty.into(), text: text.into() });
            Ok(())
        }
        fn focus(&self, tty: &str) -> Result<(), String> {
            self.calls.lock().unwrap().push(Call::Focus { tty: tty.into() });
            Ok(())
        }
        fn name_for_tty(&self, tty: &str) -> Option<String> {
            self.names.lock().unwrap().get(tty).cloned()
        }
    }
}
```

```rust
use maya_core::terminal::Terminal;
use std::path::{Path, PathBuf};
use std::process::{Command, Stdio};

pub const NOT_IN_TMUX: &str = "This session is not in tmux; only replies reach it.";

pub struct Tmux { pub binary: PathBuf }

impl Default for Tmux {
    fn default() -> Self { Self { binary: PathBuf::from("tmux") } }
}

fn sq(s: &str) -> String { maya_core::launch::shell_single_quote(s) }

pub fn new_session_args(label: &str, cwd: &Path, command: &str) -> Vec<String> {
    let inner = format!("{command}; exec \"${{SHELL:-sh}}\"");
    ["new-session", "-d", "-s", label, "-c", &cwd.to_string_lossy()].iter().map(|s| s.to_string()).chain([format!("sh -c {}", sq(&inner))]).collect()
}

pub fn send_keys_args(target: &str, text: &str) -> Vec<Vec<String>> {
    let base = |rest: &[&str]| -> Vec<String> { ["send-keys", "-t", target].iter().chain(rest).map(|s| s.to_string()).collect() };
    let mut out = Vec::new();
    let mut literal = String::new();
    let mut keys: Vec<&str> = Vec::new();
    let mut rest = text;
    while !rest.is_empty() {
        if let Some(r) = rest.strip_prefix("\x1b[B") { keys.push("Down"); rest = r; }
        else if let Some(r) = rest.strip_prefix("\x1b[Z") { keys.push("BTab"); rest = r; }
        else { let c = rest.chars().next().unwrap(); literal.push(c); rest = &rest[c.len_utf8()..]; }
    }
    if !literal.is_empty() { out.push(base(&["-l", "--", &literal])); }
    if !keys.is_empty() { out.push(base(&keys)); }
    out.push(base(&["Enter"]));
    out
}

/// `tmux list-panes -a -F '#{pane_tty}\t#{session_name}:#{window_index}.#{pane_index}\t#{session_name}'`
pub const LIST_PANES_FORMAT: &str = "#{pane_tty}\t#{session_name}:#{window_index}.#{pane_index}\t#{session_name}";

pub fn pane_for_tty(out: &str, tty: &str) -> Option<(String, String)> {
    let want = tty.trim_start_matches("/dev/");
    out.lines().filter_map(|l| { let mut f = l.split('\t'); Some((f.next()?, f.next()?, f.next()?)) })
        .find(|(t, _, _)| t.trim_start_matches("/dev/") == want)
        .map(|(_, target, session)| (target.to_string(), session.to_string()))
}

impl Tmux {
    fn run(&self, args: &[String]) -> Result<String, String> {
        let out = Command::new(&self.binary).args(args).stdin(Stdio::null()).output().map_err(|e| {
            if e.kind() == std::io::ErrorKind::NotFound { format!("tmux is not installed on {}", maya_core::net::local_hostname()) } else { format!("could not run tmux: {e}") }
        })?;
        if !out.status.success() { return Err(format!("tmux failed: {}", String::from_utf8_lossy(&out.stderr).trim())); }
        Ok(String::from_utf8_lossy(&out.stdout).into_owned())
    }
    fn pane(&self, tty: &str) -> Option<(String, String)> {
        let out = self.run(&["list-panes".into(), "-a".into(), "-F".into(), LIST_PANES_FORMAT.into()]).ok()?;
        pane_for_tty(&out, tty)
    }
}

impl Terminal for Tmux {
    fn open(&self, command: &str, cwd: &Path, label: &str) -> Result<Option<String>, String> {
        self.run(&new_session_args(label, cwd, command))?;
        Ok(Some(label.to_string()))
    }
    fn type_line(&self, tty: &str, text: &str) -> Result<(), String> {
        let (target, _) = self.pane(tty).ok_or(NOT_IN_TMUX)?;
        for args in send_keys_args(&target, text) { self.run(&args)?; }
        Ok(())
    }
    fn focus(&self, tty: &str) -> Result<(), String> {
        Err(match self.pane(tty) { Some((_, s)) => format!("Attach with: tmux attach -t {s}"), None => "Attach with: tmux attach -t <session>".into() })
    }
    fn name_for_tty(&self, tty: &str) -> Option<String> {
        self.pane(tty).map(|p| p.1)
    }
}
```

Note the `-l` literal form: tmux `send-keys -l` sends the string literally, and `--` ends option parsing so a text starting with `-` is safe. Check `maya_core::net::local_hostname` is `pub`; make it so if not.

```rust
impl CliExecutor {
    pub fn new(store: Arc<Mutex<Store>>, terminal: Arc<dyn Terminal>) -> Self { … board_due false, ttys empty … }
    fn tty_of(&self, pid: i32, registry_tty: Option<&str>) -> Option<String> {
        if let Some(t) = registry_tty { return Some(t.to_string()); }
        let mut cache = self.ttys.lock().unwrap();
        if let Some(t) = cache.get(&pid) { return Some(t.clone()); }
        let t = maya_core::tty::tty_for_pid(pid).ok()?;
        cache.insert(pid, t.clone());
        Some(t)
    }

impl Executor for CliExecutor {
    fn execute(&self, kind: CommandKind) -> Result<Option<Value>, String> {
        let l = actions::Local { store: &self.store, terminal: &*self.terminal };
        let done = |r: Result<(), String>| r.map(|_| None);
        fn data<T: serde::Serialize>(v: Result<T, String>) -> Result<Option<Value>, String> {
            v.and_then(|v| serde_json::to_value(v).map(Some).map_err(|e| e.to_string()))
        }
        match kind {
            CommandKind::Reply { session, text, attachments } => {
                let (maya_dir, exists) = { let mut s = self.store.lock().unwrap(); (s.claude_dir().join("maya"), s.card_for(&session, now_ms()).is_some()) };
                done(client::reply_with_attachments(&maya_dir, exists, &text, attachments, now_ms(), |text| actions::send_reply(&l, &session, &text)))
            }
            CommandKind::Answer { session, ask_id, question, option } => done(actions::answer_question(&l, &session, ask_id, question, option)),
            CommandKind::Compact { session } => done(actions::compact_session(&l, &session)),
            CommandKind::Rename { session, name } => done(actions::rename_session(&l, &session, &name)),
            CommandKind::SetOption { session, setting, value } => done(actions::set_session_option(&l, &session, &setting, &value)),
            CommandKind::CycleMode { session } => done(actions::cycle_session_mode(&l, &session)),
            CommandKind::Start { dir, prompt, options } => data(actions::start_session(&l, dir, prompt, options)),
            CommandKind::Resume { dir, session } => done(actions::resume_session(&l, &dir, &session)),
            CommandKind::ListResumable { dir } => data(actions::list_resumable_sessions(&l, &dir)),
            CommandKind::History { session } => data(actions::session_history(&l, &session)),
        }
    }
    fn board(&self) -> (Vec<Card>, Vec<String>) {
        let (mut cards, root, ttys) = { let mut s = self.store.lock().unwrap(); let cards = s.refresh(now_ms()); let ttys: Vec<Option<String>> = cards.iter().map(|c| s.session(&c.session_id).and_then(|r| r.tty).or_else(|| s.foreign(&c.session_id).and_then(|f| f.tty))).collect(); (cards, s.config.projects_dir_path(), ttys) };
        for (c, tty) in cards.iter_mut().zip(ttys) {
            c.terminal = self.tty_of(c.pid, tty.as_deref()).and_then(|t| self.terminal.name_for_tty(&t));
        }
        let dirs = root.filter(|r| r.is_dir()).map(|r| launch::list_project_dirs(&r)).unwrap_or_default();
        (cards, dirs)
    }
    fn board_requested(&self) -> bool { self.board_due.swap(false, Ordering::SeqCst) }
}
```

```rust
pub fn preflight(config: &Config, existing: Option<&RunStatus>, alive: &dyn Fn(u32) -> bool) -> Result<(), (i32, String)> {
    match config.network.role {
        NetworkRole::Main => return Err((2, "the CLI is assistant-only".into())),
        NetworkRole::Off => return Err((2, "run `maya pair` first".into())),
        NetworkRole::Assistant if config.network.token.is_empty() || config.network.assistant_id.is_empty() => return Err((2, "run `maya pair` first".into())),
        NetworkRole::Assistant => {}
    }
    if let Some(s) = existing { if s.pid != std::process::id() && alive(s.pid) { return Err((2, format!("maya run is already running (pid {})", s.pid))); } }
    Ok(())
}

pub fn run(claude_dir: &Path) -> i32 {
    let maya_dir = claude_dir.join("maya");
    let mut store = Store::new(claude_dir.to_path_buf());
    store.compact_events();
    if let Err((code, msg)) = preflight(&store.config, status_file::read(&maya_dir).as_ref(), &|pid| maya_core::registry::pid_alive(pid as i32)) { eprintln!("{msg}"); return code; }
    let _ = log::init(&maya_dir.join("maya-cli.log"));
    log::install_emitter(|l| println!("{}", log::file_line(l)));
    log::line("cli", format!("maya {} run started", env!("CARGO_PKG_VERSION")));
    match hook_install::status(claude_dir) { Ok(true) => {}, _ => log::line("cli", "hooks are not installed: sessions will not be seen (run `maya hooks install`)") }
    let store = Arc::new(Mutex::new(store));
    let stop = Arc::new(AtomicBool::new(false));
    install_signal_handlers(stop.clone());          // SIGINT, SIGTERM → stop
    let exec = Arc::new(CliExecutor::new(store.clone(), Arc::new(Tmux::default())));
    let notify: Arc<dyn ClientNotify> = Arc::new(CliNotify { maya_dir: maya_dir.clone(), stop: stop.clone() });
    { let (s, due) = (store.clone(), exec.board_due.clone()); let sessions_dir = claude_dir.join("sessions"); let md = maya_dir.clone(); std::thread::spawn(move || watcher::run(&sessions_dir, &md, Duration::from_secs(5), || { s.lock().unwrap().refresh(now_ms()); due.store(true, Ordering::SeqCst); })); }
    let config_of = { let s = store.clone(); move || s.lock().unwrap().config.network.clone() };
    client::reconnect(&config_of, exec, notify, &stop);
    status_file::remove(&maya_dir);
    log::line("cli", "stopped");
    if stop.load(Ordering::SeqCst) && status_file::read(&maya_dir).is_none() { 0 } else { 1 }
}
```

Signals: a `static STOP: OnceLock<Arc<AtomicBool>>` and `extern "C" fn on_signal(_: libc::c_int) { if let Some(s) = STOP.get() { s.store(true, Ordering::SeqCst) } }` registered with `libc::signal(libc::SIGINT, on_signal as libc::sighandler_t)` and the same for `SIGTERM`. The client's tick loop polls `stop` every 100 ms, so a signal ends `run` within a second with a clean close. Note `reconnect` returns on `REMOVED`/`NOT_PAIRED` too: those return 1 (the status file still holds the error); a signal returns 0.

The watcher's `refresh` must not hold the store lock long; it is the same call the app makes.

`config_of` re-reads the in-memory config each attempt; `run` also re-loads the file on each attempt (`config::load(&config_path)` into the store before `config_of` returns it), so a config edited on disk to `role: off` or `main` makes `run_once` fail with `NOT_PAIRED`, `reconnect` returns, and `run` exits 2 with `the config is no longer an assistant's; stopping`. Test in `preflight`'s spirit: a unit test on the small `fn exit_code_for(stopped_by_signal: bool, config: &Config) -> i32` that returns 0 for a signal, 2 when the role is not Assistant, 1 otherwise.

```yaml
      - uses: swatinem/rust-cache@v2
      - name: Install tmux for the integration test
        run: sudo apt-get update && sudo apt-get install -y tmux
      - name: Test core and the CLI on Linux
        run: cargo test -p maya-core -p maya-cli
      - name: Build Linux binaries
        if: needs.macos.outputs.release == 'true'
        run: |
          cargo install cross --locked
          cross build -p maya-cli --release --target x86_64-unknown-linux-musl
          cross build -p maya-cli --release --target aarch64-unknown-linux-musl
          mkdir -p dist-linux
          cp target/x86_64-unknown-linux-musl/release/maya dist-linux/maya-linux-x86_64
          cp target/aarch64-unknown-linux-musl/release/maya dist-linux/maya-linux-aarch64
      - name: Attach to the release
        if: needs.macos.outputs.release == 'true'
        env:
          GH_TOKEN: ${{ github.token }}
          VERSION: ${{ needs.macos.outputs.version }}
        run: gh release upload "v${VERSION}" dist-linux/* --clobber
```

The `needs: macos` makes the upload run after `gh release create`. `cargo test -p maya-core` on Linux is the guard that core stays free of macOS-only code: if `notify.rs` or `foreign.rs` fail to compile there, fix them with `#[cfg(target_os = "macos")]` on the offending function and a portable fallback (e.g. `focus_active()` returns false off macOS), not by moving them.
